# On
An ad-free, minimalist app for storing workout routines and tracking training consistency. I developed this app during my own time going to the gym. I used to rely on a standard calendar, but I wanted something simpler and more dynamic.

The app allows you to create workout routines (using exercises of your choice) and includes features I found useful—such as the ability to shift a workout to the next day—making it very easy to adjust your daily schedule.

Workouts marked as completed for the current day are logged in the calendar. Once a day's workout is marked, it can only be modified via the calendar tab. For example: if you mark Thursday's workout as completed using Routine A, but later switch to Routine B (which involves different exercises), the calendar will still record the completion of Routine A, as originally marked.

Consistency and charts: the app features a consistency tracker that updates as you log completed workouts. It tracks activity from Monday to Sunday. Weekend workouts count if logged; if no workout is marked on those days, they are treated as rest days, so your consistency streak remains intact. A chart displaying the last 16 weeks of training updates from bottom to top—running Monday through Sunday—providing an overview of how often you went to the gym each week.

The goal was to create an app that is as simple and lightweight as possible, allowing anyone to use it however they like while maintaining a minimalist, practical approach. It is designed for users who already know how to create a workout routine—or already have one—but have grown tired of overly complicated gym apps.
